Aplikacja

voiceflow działa w całości na Twoim komputerze. Nagrania, transkrypcje, historia, słownik i konfiguracja są przechowywane lokalnie i nigdzie nie są wysyłane. Aplikacja wykonuje dokładnie dwa rodzaje połączeń sieciowych:

  • Pobranie modelu — jednorazowo, z Hugging Face, przy instalacji lub zmianie modelu mowy;
  • Sprawdzenie aktualizacji — opcjonalne, anonimowe zapytanie do API GitHuba najwyżej raz dziennie (wyłączysz je przez updates.check: false w konfiguracji).

Nie ma telemetrii, nie ma analityki, nie ma konta. Kod źródłowy jest publiczny — wszystko można zweryfikować.
