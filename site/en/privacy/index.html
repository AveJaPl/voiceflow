Privacy

Last updated: 16 September 2026

On-device dictation

VoiceFlow on Mac and iPhone recognizes speech locally using a downloaded Whisper model. While the iPhone model is unavailable, the app uses Apple speech recognition with on-device processing required. Recordings are not sent to the account service. Local history contains the recognized text.

Optional account and sync

After you sign in, the app sends dictation text, date, duration and device source to the configured account server. The Mac may also upload earlier local history. The account shares history and vocabulary between your devices. The server stores your email address, password hash, access token and synced data. Apple devices store the access token in Keychain.

Signing out stops sync from that device; it does not delete data already stored on the server. Account history entries can be deleted in the app. Contact your server operator about other stored data. Never post transcripts or credentials in public GitHub issues.

Rooms and your own server

When you join a room, VoiceFlow sends the device name, presence events and dictation statistics. Anyone with the room code can view its ranking. The ranking does not contain recordings or dictation text.

If you configure an external transcription server or local engine sharing on Mac, audio travels between the device and the selected server. That server's operator determines how it handles and retains the data.

Models and updates

The app downloads models from Hugging Face. The Mac checks the GitHub releases API at startup and every six hours, then downloads available updates. These providers receive ordinary connection information, including your IP address; the requests do not include transcripts.

This website

This website uses a self-hosted Umami instance for visitor statistics and loads fonts from Google Fonts. Your browser connects to these services and sends the information needed for a connection, including your IP address. Website analytics do not receive dictation text from the app.

Contact

Report bugs and technical questions through GitHub. Issues are public; do not include confidential data.
